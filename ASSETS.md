# Arquivos visuais e áudio

O código Remotion e a documentação deste episódio estão publicados nesta branch. Os arquivos binários são entregues privadamente à Iza em:

- `Acervo-visual-episodio-01.zip`: imagens originais, peças, cenários, camadas, áudio e quadros de revisão, com caminhos iguais aos usados pelo projeto.
- `beleza-01-tall-tale.mp4`: vídeo 1080×1920, 30fps, 68,8s.

Para reproduzir, extraia o ZIP na raiz do repositório, preservando as pastas `assets/` e `projects/`. Depois siga o README do episódio. Não há chave de API nem upload público automático.

A publicação dos binários no GitHub foi bloqueada pela revisão automática por não conseguir verificar blocos codificados. Nenhum mecanismo de reconstituição pública ou workflow foi publicado para contornar essa decisão. Os originais foram preservados e entregues privadamente.
